# Toybox Trader

A kid-friendly stock & crypto trading simulator, built as a single-file React app.

Kids get a play-money portfolio to learn how markets work — buying and selling
stocks and crypto with fake cash, earning rewards, and picking up basic
investing concepts through a colorful, game-like interface.

## Files

- `ToyboxFull.jsx` — the complete app in a single React component file.

## Status

Early standalone project — hosting (Netlify) and a database (Neon) are not set up yet.
