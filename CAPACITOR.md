# Building the iOS / Android app (Capacitor)

Toybox Trader is wrapped with [Capacitor](https://capacitorjs.com). The web app
(built into `dist/`) is bundled inside a native shell you submit to the App
Store and Google Play. API calls (Neon sync, prices, Telegram, push) go to the
live server automatically — see `src/api.ts`.

## Prerequisites
- **iOS:** a **Mac** with **Xcode** + CocoaPods (`sudo gem install cocoapods`).
- **Android:** **Android Studio** (any OS).
- Node 18+ and this repo cloned, then `npm install`.

## One-time: create the native projects
```bash
npm run build            # produces dist/
npx cap add ios          # Mac only — creates ios/
npx cap add android      # creates android/
```

## Every time you change the app
```bash
npm run build
npx cap sync             # copies dist/ + plugins into the native projects
```

## Open & run
```bash
npx cap open ios         # opens Xcode      → pick a device → Run
npx cap open android     # opens Android Studio → Run
```

## App icons & splash screen
The polished source art is already in **`resources/`**:
- `resources/icon.png` — 1024×1024 teddy app icon (safe-zoned for Android adaptive icons)
- `resources/splash.png` / `resources/splash-dark.png` — 2732×2732 splash screens

Generate every native density (icons + splash, for both iOS and Android) with one
command — run it after the platforms exist (`cap add`), on a machine with normal
network access (the tool pulls the `sharp` image library):
```bash
npm install --save-dev @capacitor/assets
npx @capacitor/assets generate --iconBackgroundColor '#7c3aed' --iconBackgroundColorDark '#7c3aed' --splashBackgroundColor '#0d0621' --splashBackgroundColorDark '#0d0621'
```
This writes all the mipmap/adaptive icons and splash drawables into `android/`
(and `ios/` if present). Then `npx cap sync` and build.

> Note: this couldn't be pre-generated in the build environment because `sharp`'s
> binary download was blocked there — it installs fine on a normal machine.

## Submitting
1. **iOS:** in Xcode set your Team/signing + bundle id (`com.toyboxtrader.app`),
   archive, and upload via App Store Connect.
2. **Android:** in Android Studio generate a signed **App Bundle (.aab)** and
   upload to the Play Console.

## Notes / follow-ups
- **Push notifications:** the current push uses **Web Push**, which works in the
  browser/installed PWA. Native iOS/Android apps use APNs/FCM instead — to enable
  push inside the wrapped app you'll add `@capacitor/push-notifications` plus a
  Firebase project (Android) and an Apple Push key (iOS). Not required to ship;
  it's a later enhancement.
- **`ios/` and `android/` folders** are generated by `cap add`. You can commit
  them (recommended, so builds are reproducible) or keep them local and
  regenerate — your choice.
- Update `LIVE_ORIGIN` in `src/api.ts` if the site ever moves off
  `toytrader.netlify.app`.
